# 🔊 Sprachdateien für Masri Lernen

Lege hier **MP3- oder OGG-Dateien** ab – die App spielt sie als offizielle Aussprache ab (besser als Computer-Stimme).

## Benennung

| Variante | Beispiel |
|----------|----------|
| **Über Excel-Spalte** `audio_datei` | `brot.mp3` → Datei heißt `brot.mp3` |
| **Automatisch per deutschem Wort** | „Brot" → Datei `brot.mp3` (Kleinbuchstaben, Umlaute ersetzt) |
| **Automatisch per ID** | Vokabel-ID `l1` → Datei `l1.mp3` |

## Excel-Spalte

```
kategorie,deutsch,aegyptisch,aussprache,geschlecht,typ,notiz,audio_datei
Lebensmittel,Brot,عيش,Aisch,n,word,,brot.mp3
```

## Tipps für gute Aufnahmen

- Format: **MP3** (128 kbps reicht) oder **OGG**
- Kurz und klar, eine Datei pro Wort
- Quellen: selbst aufnehmen, Forvo.com (Privatgebrauch), Muttersprachler

## Offline

Nach dem Online-Hosting: In der App **Meine Wörter → „Offline-Paket laden“** tippen – dann sind Vokabeln + Audio auch ohne Internet verfügbar.
